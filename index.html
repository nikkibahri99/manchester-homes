X1's Manchester developments (X1 Manchester Waters, X1 The Plaza, X1 Eastbank Tower, etc.) run well above both budgets — their cheapest 1-beds start around £1,025–£1,200 pcm, and 2-beds start around £1,450 pcm. Every unit is also built around shared amenities (on-site gyms, cinema rooms, overnight concierge/security), which is their whole model — so they wouldn't fit the "no communal areas" ask for the 1-bed search even if the price worked. Skipped rather than force a bad fit.
